# ProcessManager🚀
> Современный диспетчер процессов с управлением приоритетами, CPU Affinity и иерархией

---

## Описание🌬️
**ProcessManager** - это кроссплатформенный инструмент для мониторинга и управления процессами операционной системы.  
Приложение позволяет в реальном времени наблюдать за запущенными процессами, менять их приоритеты, привязывать к конкретным ядрам процессора, просматривать потоки, строить дерево иерархии и визуализировать загрузку системы.

---

## Основные возможности👨🏿‍🔬
- Полный список процессов с PID, именем, приоритетом, памятью, количеством потоков и временем CPU
- Сортировка и поиск по любому столбцу
- Фильтрация: все процессы / только с интерфейсом / системные
- Изменение приоритета (Idle → Realtime) с предупреждением для критических уровней
- Управление CPU Affinity через чекбоксы (привязка к ядрам)
- Просмотр потоков выбранного процесса (ID, состояние, приоритет, время CPU)
- Построение дерева процессов (родитель → потомки)
- Завершение процессов (Kill)
- Графики: загрузка CPU по ядрам + топ-10 процессов по памяти (ScottPlot)
- Автообновление данных каждые 3 секунды (настраиваемый интервал)

## Как скачать и запустить🤓

1. Перейдите в репозиторий:  
   https://github.com/jota2069/ProcessManager

2. Скачайте проект:
   - Нажмите зелёную кнопку **Code** → **Download ZIP**  
   - Или клонируйте через терминал:
     ```bash
     git clone https://github.com/jota2069/ProcessManager.git
     cd ProcessManager
     ```

3. Установите .NET 8 SDK (если ещё не установлен):  
   https://dotnet.microsoft.com/download/dotnet/8.0

4. Восстановите пакеты и соберите проект:
   ```bash
   dotnet restore
   dotnet build
   ```

5. Запустите:
   ```bash
   dotnet run
   ```

   или откройте проект в **Rider** / **Visual Studio** и нажмите F5.

**Поддерживаемые ОС**: Linux, Windows 10/11
